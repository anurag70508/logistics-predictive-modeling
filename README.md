### Week 4: Predictive Modeling and Optimization in Logistics Systems
**File:** `logistics_predictive_model.py`
* **Objective:** Develop an end-to-end predictive machine learning model to forecast delivery durations and propose actionable route optimization strategies.
* **Key Features:**
  * Implements a **Random Forest Regressor** to handle complex, non-linear relationships between traffic, weather, and distance.
  * Conducts rigorous hyperparameter tuning and model validation using **GridSearchCV** and **5-Fold Cross-Validation**.
  * Evaluates performance using rigorous statistical metrics (MAE, RMSE, R-squared).
  * Extracts **Feature Importance** to inform dynamic routing protocols and strategic resource allocation (e.g., assigning highly experienced drivers to complex routes).
